# Magpie 报错了，按这里做

其余章节保留原 Magpie Experimental 0.6.8 说明。DLSSNR 章节已按 2026-10-13 功能分支更新，适用于包含“当前 DLSSNR 会话”状态区的构建。

**不用整篇读。按 Ctrl + F，输入报错里的一两个词，找到对应那一项，从第 1 步开始做。**

- 每项先用一句话说明出了什么问题，下面是要做的操作。能正常用了，就可以停。
- 找不到按钮时，可以点步骤里的操作说明或“点这里”，查看位置。
- 做不下去或做完仍报错，就[把 logs 打包发来](#feedback)，我们看里面的记录。

**如果提示“尚未保存”，先别关 Magpie，也别重启电脑。直接看[设置或参数存不下来](#error-28)。**

## 一、DLSSNR、NVIDIA VSR 和 RTX Video HDR

<a id="error-1"></a>

### 1. DLSSNR 未运行或报错

先看主页或浮层状态：**已跳过**表示效果组仍显示画面、DLSSNR 没有处理；**效果组已停止**表示整组停止。**HDR 参数正常受限**不代表后端故障。只有“DLSSNR 正在运行”确认处理已恢复。

打开“最近一次问题 → 查看详情”，按检测结果选择步骤：

1. **已确认 DLL 缺失、加载失败或接口不完整**：打开程序目录和恢复说明。完全退出 Magpie，按当前版本运行包说明恢复完整匹配文件，或解压到新目录比较；保留原配置。
2. **当前渲染显卡不是 NVIDIA**：打开本次配置的“渲染显卡”。只有确实存在兼容显卡时才改选，否则在相关效果组中移除 DLSSNR。
3. **驱动或功能库需要更新、组合不支持**：对照本版本运行包要求，核对详情中的实际 GPU/PCI ID、驱动和 DLL 版本。不能仅凭返回值确定是哪一项不匹配；要求不明确时先复制诊断反馈。
4. **内存资源不足**：关闭其他 GPU 高占用程序，降低源分辨率，或将大于 1 的 Multi Pass 降为 1，再启用效果组。
5. **NGX 已被保护性禁用**：从托盘完全退出 Magpie，重新打开后再启用；仅开关效果组无效。
6. **访问失败或未知原因**：查看具体失败操作。按[完整恢复说明](DLSSNR-TROUBLESHOOTING.md)处理；再次失败时复制诊断并附对应日志。不要无依据地更换 DLL、更新驱动或改用管理员权限。

恢复后在当前状态区确认“正在运行”。详情会尝试定位实际效果组和效果器；对象已经改变时给出列表入口。历史问题不会替代当前状态。

旧指南中的固定 `615+` 门槛、显卡系列/DLL 对照及通用管理员建议不再作为 DLSSNR 的判断依据。完整步骤见 [DLSSNR 状态与恢复](DLSSNR-TROUBLESHOOTING.md)。

<a id="error-2"></a>

### 2. NVIDIA VSR 打开就报错

NVIDIA VSR 没有成功启动。先换个文件夹运行一次。

**相关报错：** NVIDIA VSR 暂未启动、NVIDIA VSR 初始化失败、错误 -2

**检查步骤：**

1. [退出 Magpie](#quit)。
2. 打开“此电脑 → C 盘”，新建一个空文件夹，名字填 `Magpie-test`。已有同名文件夹，就用 `Magpie-test2`。
3. 把完整安装包[解压到刚建的文件夹](#unpack)。打开里面的 `Magpie.exe`，再试一次 NVIDIA VSR。
4. 还不行，把 **logs 文件夹打包发来**。[怎么发，点这里](#feedback)。

<a id="error-3"></a>

### 3. RTX Video HDR 打开就报错

RTX Video HDR 没有成功处理画面。

**相关报错：** RTX Video HDR 未能完成处理、RTX Video HDR 不可用

**检查步骤：**

1. 先[看显卡型号](#gpu-model)。需要 NVIDIA RTX 20、30、40 或 50 系显卡；例如 RTX 2060、3060、4060、5070。型号不在这些系列里，先把型号截图反馈。
2. 打开 NVIDIA App，点“驱动程序”。有新版本就下载并安装，装完重启电脑。[不会更新，点这里](#drivers)。
3. [重新解压完整安装包](#unpack)，打开新文件夹里的 Magpie，选回之前用的效果组，再试一次。
4. 还不行，把 **logs 文件夹打包发来**。[怎么发，点这里](#feedback)。

## 二、补帧和光流

<a id="error-4"></a>

### 4. 补帧打不开，或用着用着自动关了

补帧没有正常工作。画面还在动，也可能已经停止补帧。

**相关报错：** 补帧初始化失败、DLSS 补帧或 XeSS 补帧未能启动、补帧连续失败后停用、补帧自动关闭、XeSSFG 多帧兼容失败、运行库版本校验失败、补帧倍率或光流组合不支持

**检查步骤：**

1. [打开补帧效果器的设置](#parameters)，把倍率改成 **2×**。没有倍率选项就跳过。
2. 在同一个面板里，把“光流方法”改成“无”或“不使用”，先试一次。
3. 按[这里的步骤更新显卡驱动](#drivers)，安装完重启电脑，再试一次。
4. 还报错就[重新解压 0.6.8 完整安装包](#unpack)。打开新文件夹里的 Magpie，选回之前的效果组，再试一次。
5. 仍报错，或者只能用 2×、改回原倍率就报错，把 **logs 文件夹打包发来**。[怎么发，点这里](#feedback)。

<a id="error-5"></a>

### 5. 提示补帧只能放一个

同一个效果组里放了两个或更多补帧效果器。

**相关报错：** 效果组包含多个补帧效果器、补帧效果器冲突

**检查步骤：**

1. [打开正在使用的效果组](#parameters)，找到名字里带“补帧”的几行。
2. 只留一个你要用的补帧。点多余那一行右边的垃圾桶按钮，删除那一项。
3. [重新启用效果组](#retry)。
4. 还不行，把 **logs 文件夹打包发来**。[怎么发，点这里](#feedback)。

<a id="error-6"></a>

### 6. 开启光流就报错

选中的光流设置没有成功启动。

**相关报错：** NVIDIA 光流未启动、AMD 光流未启动、光流方法不可用、光流质量不支持、光流共享资源创建失败、光流互操作失败

**检查步骤：**

1. [打开报错效果器的设置](#parameters)，把“光流质量”改成“性能”，再试一次。
2. 用的是 NVIDIA 光流，就[打开这次出错的设置](#profile)，在“性能 → 显示卡”里选带 **NVIDIA** 字样的那张。
3. 列表里没有 NVIDIA 显卡，就回到效果器的“参数”，把“光流方法”改成“AMD 光流”。
4. 按[这里的步骤更新显卡驱动](#drivers)，安装完重启电脑，再试一次。
5. 还不行，把 **logs 文件夹打包发来**。[怎么发，点这里](#feedback)。

<a id="error-7"></a>

### 7. 提示几个光流设置不一样

程序已把这些设置统一了。画面正常时可以继续用；想去掉提示，再做下面几步。

**相关报错：** 光流估计方法或档位不一致、多个效果器的光流设置被统一

**检查步骤：**

1. [打开正在使用的效果组](#parameters)，找到提示里写出的几个效果器。
2. 点开第一个效果器的“参数”，记下“光流方法”和“光流质量”选了什么。
3. 把另外几个效果器的这两个选项改成一样，然后[重新启用效果组](#retry)。
4. 还不行，把 **logs 文件夹打包发来**。[怎么发，点这里](#feedback)。

## 三、效果器和效果组

<a id="error-8"></a>

### 8. 选好效果后，还是启动失败

效果没有成功打开。先恢复刚改的数值，再检查安装包。

**相关报错：** AI 效果器初始化失败、效果器未能启动、效果器编译失败、编译效果失败、效果组初始化失败、无法启用效果组

**检查步骤：**

1. [打开报错效果器的设置](#parameters)，把刚改过的数值改回原值。忘了原值，且改的是滑条，就双击那根滑条。
2. 报错的是 DLSSNR，就把“Multi Pass”改成 **1**，再试一次。
3. 还报错就[重新解压完整安装包](#unpack)。打开新文件夹里的 Magpie，选回之前的效果组，再试一次。
4. 效果器是别人单独发来的，就请对方重新发一份，并告诉你放在哪个文件夹。
5. 还不行，把 **logs 文件夹打包发来**。[怎么发，点这里](#feedback)。

<a id="error-9"></a>

### 9. 效果列表里有一项显示失效

程序找不到这一项，或者这一项保存的设置已经损坏。

**相关报错：** 不可用效果器、未知效果器、找不到对应效果文件、失效效果器、此项配置无法完整恢复

**检查步骤：**

1. [重新解压完整安装包](#unpack)，打开新文件夹里的 Magpie，再看这一项是否还报错。
2. 这一项是别人单独发来的，就请对方重新发文件，并告诉你放在哪个文件夹。
3. 仍显示“此项配置无法完整恢复”的，先把这一行截图，再点这一行右边的垃圾桶删除它。点“添加效果器”，重新添加同一项，并放回原位置。找不到这项或不会放回原位置，就带截图反馈。
4. 还不行，把 **logs 文件夹打包发来**。[怎么发，点这里](#feedback)。

<a id="error-10"></a>

### 10. 提示没有选效果组，或里面是空的

还没有告诉 Magpie 要使用哪一套效果，或者选中的那套效果里没有内容。

**相关报错：** 当前配置没有可用的效果组、尚未选择可用的效果组、效果组目前为空

**检查步骤：**

1. [打开这次出错的设置](#profile)，在“常规 → 效果组”里选一个已有的名字，不要选“无”。
2. 点 Magpie 左侧“效果组”，点开刚才选的那个名字。
3. 里面没有效果器，就点“添加效果器”，选一个你要用的效果。[重新启用效果组](#retry)。
4. 还不行，把 **logs 文件夹打包发来**。[怎么发，点这里](#feedback)。

<a id="error-11"></a>

### 11. 两个效果组名字一样

两个组用了同一个名字，把其中一个改名即可。

**相关报错：** 旧配置中存在同名效果组、此名称与其他效果组重复

**检查步骤：**

1. 点 Magpie 左侧“效果组”，找到名字一样的两个组。
2. 点其中一个组名旁边的铅笔按钮，在名字后面加上 `2`，再点“确定”。
3. 如果提示“重复名称已自动添加序号”，已经处理好了，可以继续用。
4. 还不行，把 **logs 文件夹打包发来**。[怎么发，点这里](#feedback)。

## 四、游戏或视频窗口

<a id="error-12"></a>

### 12. 抓不到游戏或视频画面

Magpie 没能拿到你要处理的画面。

**相关报错：** 捕获失败、无法捕获目标窗口、请还原目标窗口、捕获方式不可用、当前系统会话无法使用所选捕获方式

**检查步骤：**

1. 点任务栏上的游戏或播放器图标，把窗口打开，放到屏幕中间。
2. [打开这次出错的设置](#profile)，把“常规 → 捕获方式”改成 **Graphics Capture**。
3. [退出 Magpie](#quit)，重新打开。回到游戏或视频窗口，点一下窗口，再按启用效果的快捷键。
4. 还不行，把 **logs 文件夹打包发来**。[怎么发，点这里](#feedback)。

<a id="error-13"></a>

### 13. 提示程序窗口找不到，或这个窗口不能用

Magpie 没有选中一个能正常显示内容的窗口。

**相关报错：** 目标窗口已关闭、无响应、源窗口已不可用、无法为这个窗口启用效果组、窗口小于 64 × 64 像素、窗口位于屏幕之外、无法读取窗口尺寸、不支持透明窗口、裁剪区域无效

**检查步骤：**

1. 打开要处理的游戏或播放器，点它真正显示内容的窗口。窗口写着“未响应”时，先关闭再打开。不要点帧率小窗或桌面挂件。
2. 游戏在“设置 → 画面”里改成“窗口化”。普通软件铺满屏幕时，点右上角“×”旁边的还原按钮。
3. 把窗口拖到屏幕中间，调成大约半个屏幕大小。窗口跑到别的屏幕上了，先点它的任务栏图标，再按 **Win + Shift + 左方向键** 或 **Win + Shift + 右方向键**。
4. [打开这次出错的设置](#profile)，把“源窗口 → 自定义裁剪”关掉，再试一次。
5. 还不行，把 **logs 文件夹打包发来**。[怎么发，点这里](#feedback)。

<a id="error-14"></a>

### 14. 游戏全屏时用不了，或效果窗口打不开

先让游戏在小窗口里运行，再用 Magpie 的窗口模式试一次。

**相关报错：** 禁止为最大化或全屏窗口启用效果组、源应用已最大化或全屏、3D 游戏模式不支持窗口模式、Desktop Duplication 不支持窗口模式、无法创建画面输出、无法创建输出窗口

**检查步骤：**

1. 进入游戏的画面设置，把“全屏”改成“窗口化”，把窗口调到小于屏幕。
2. [打开这次出错的设置](#profile)，把“常规 → 3D 游戏模式”关掉。
3. 在同一页，把“捕获方式”改成 **Graphics Capture**。
4. 看 Magpie 主页上“效果组快捷键（窗口模式）”写的是哪几个键，回到游戏，按那组键启用。
5. 还不行，把 **logs 文件夹打包发来**。[怎么发，点这里](#feedback)。

<a id="error-15"></a>

### 15. 提示游戏窗口的权限比 Magpie 高

需要重新以管理员身份打开 Magpie。

**相关报错：** 目标窗口的权限高于 Magpie、启用效果组时提示目标窗口权限过高

**检查步骤：**

1. [退出 Magpie](#quit)。
2. [打开 Magpie 程序文件夹](#program-folder)，右键点 `Magpie.exe`，选“以管理员身份运行”。弹出确认窗口时点“是”。
3. 回到游戏或视频窗口，再试一次。
4. 还不行，把 **logs 文件夹打包发来**。[怎么发，点这里](#feedback)。

## 五、显卡、屏幕、工具栏和触控

<a id="error-16"></a>

### 16. 开启效果时，提示显卡出错

显卡没能完成这次画面处理。先减少同时运行的程序，再试一次。

**相关报错：** 图形设备初始化失败、无法创建纹理或渲染资源、显卡无法创建同步资源、图形设备无法共享输出画面、共享纹理打开失败

**检查步骤：**

1. 关闭其他正在运行的游戏，以及暂时不用的直播、剪辑软件。
2. 按[这里的步骤更新显卡驱动](#drivers)，安装完重启电脑。
3. [打开这次出错的设置](#profile)，找到“性能 → 显示卡”。列表里有另一张显卡就换一张试试；只有一张就跳过。
4. 在游戏画面设置里，把分辨率改小一档，例如从 3840×2160 改成 2560×1440。处理视频时，把播放器窗口拖小一些，再试一次。
5. 还不行，把 **logs 文件夹打包发来**。[怎么发，点这里](#feedback)。

<a id="error-17"></a>

### 17. 提示已经有一个效果窗口在运行

另一份 Magpie 或之前的效果画面还没有关闭。

**相关报错：** 已存在其他输出窗口、已有其他效果组正在运行

**检查步骤：**

1. 在电脑右下角找到 Magpie 图标，右键点“退出”。有几个 Magpie 图标，就逐个退出。
2. 只打开一次 `Magpie.exe`。
3. 回到游戏或视频窗口，再启用效果。
4. 还不行，把 **logs 文件夹打包发来**。[怎么发，点这里](#feedback)。

<a id="error-18"></a>

### 18. 提示找不到所选的屏幕

之前选的屏幕现在不能用了，先改回正在使用的屏幕。

**相关报错：** 当前显示器布局无法用于全屏模式、所选显示器未连接

**检查步骤：**

1. 把游戏或视频窗口拖到你正在看的屏幕上。
2. [打开这次出错的设置](#profile)，在“常规 → 首选的显示器”里选“距离源窗口最近的显示器”。
3. 回到游戏或视频窗口，再试一次。
4. 还不行，把 **logs 文件夹打包发来**。[怎么发，点这里](#feedback)。

<a id="error-19"></a>

### 19. 工具栏打不开，或鼠标显示不正常

画面顶部的工具栏或鼠标显示没有正常工作。

**相关报错：** 工具栏或光标叠加层初始化失败、3D 游戏模式不支持工具栏

**检查步骤：**

1. [打开这次出错的设置](#profile)，把“常规 → 3D 游戏模式”关掉。
2. [退出 Magpie](#quit)，重新打开，再启用效果。
3. 还报错就[重新解压完整安装包](#unpack)，从新文件夹打开 Magpie，再试一次。
4. 还不行，把 **logs 文件夹打包发来**。[怎么发，点这里](#feedback)。

<a id="error-20"></a>

### 20. 触摸屏操作没有反应

在 Magpie 画面里用手指点击、拖动时，没有正常反应。

**相关报错：** 触控支持组件启动失败、触控支持不可用

**检查步骤：**

1. [退出 Magpie](#quit)。
2. 在[程序文件夹](#program-folder)里右键点 `Magpie.exe`，选“以管理员身份运行”，弹出确认窗口时点“是”。
3. 打开 Magpie“主页 → 触控支持”，把“启用触控支持”打开，再试一次。
4. 还不行，把 **logs 文件夹打包发来**。[怎么发，点这里](#feedback)。

<a id="error-21"></a>

### 21. 点“显示原图”没有成功

暂时不能切回原来的画面做对比。

**相关报错：** 暂时无法显示原图、原图对比不可用

**检查步骤：**

1. 让视频继续播放，或在游戏里动一下，再点“显示原图”。
2. 还不行就[停用效果后重新启用](#retry)。
3. 回到画面，再点一次“显示原图”。
4. 还不行，把 **logs 文件夹打包发来**。[怎么发，点这里](#feedback)。

<a id="hdr"></a>

## 六、HDR

<a id="error-22"></a>

### 22. HDR 效果放重复了，或顺序放错了

同一张画面被重复转换，前后两个 HDR 效果接不上。第 2、3 步只做与报错文字对应的那一步。

**相关报错：** HDR → SDR 前面的画面已经是 SDR、SDR → HDR 或 RTX Video HDR 需要 SDR 输入

**检查步骤：**

1. [打开正在使用的效果组](#parameters)，先把整个效果器列表截图。
2. 报错写着“HDR → SDR 前面的画面已经是 SDR”：找到报错那一行“HDR → SDR”，点它右边的垃圾桶删除。
3. 报错写着“SDR → HDR 或 RTX Video HDR 需要 SDR 输入”：从报错那一行往上看，找到最近的一项“SDR → HDR”或“RTX Video HDR”，先删除上面这一项。分不清是哪一行，就先把截图发来。
4. [重新启用效果组](#retry)。
5. 还不行，把 **logs 文件夹打包发来**。[怎么发，点这里](#feedback)。

<a id="error-23"></a>

### 23. 提示“没有可恢复的兼容映射”

“SDR → HDR”选的模式不适合现在这套效果，先改成自动。

**相关报错：** 当前没有可恢复的兼容映射、HDR 兼容配对缺失

**检查步骤：**

1. [打开正在使用的效果组](#parameters)，找到“SDR → HDR”，点这一行右边的“参数”。
2. 点开“转换模式”的列表，选“自动：配对恢复／SDR 白点映射”。
3. [重新启用效果组](#retry)。
4. 还不行，把 **logs 文件夹打包发来**。[怎么发，点这里](#feedback)。

<a id="error-24"></a>

### 24. 提示“需要保留 HDR 源画面”

这套效果需要 HDR 画面。先打开屏幕的 HDR，再换一下捕获方式。

**相关报错：** HDR → SDR 需要保留 HDR 源画面、HDR 捕获需要 Graphics Capture

**检查步骤：**

1. 右键点桌面空白处，选“显示设置”。点游戏或视频所在的那块屏幕，找到“HDR”，打开“使用 HDR”。找不到开关，就先反馈。
2. [打开这次出错的设置](#profile)，把“常规 → 捕获方式”改成 **Graphics Capture**。
3. 回到游戏或视频窗口，再启用效果。
4. 还不行，把 **logs 文件夹打包发来**。[怎么发，点这里](#feedback)。

<a id="error-25"></a>

### 25. 提示“需要开启目标屏幕 HDR”

这套效果输出的是 HDR 画面，显示它的屏幕也要配合设置。

**相关报错：** 效果组输出 HDR、需要开启目标屏幕 HDR

**检查步骤：**

1. 右键点桌面空白处，选“显示设置”，为显示 Magpie 画面的屏幕打开“使用 HDR”。用了几块屏幕显示，就分别打开。
2. 没有 HDR 开关，或者不想开，就[打开效果组](#parameters)，点组底部的“添加效果器”，添加“HDR → SDR”。
3. 把新加这一项放在列表最后，点它的“参数”，将“转换模式”设为“SDR 显示映射”，再试一次。
4. 还不行，把 **logs 文件夹打包发来**。[怎么发，点这里](#feedback)。

## 七、设置和参数

<a id="error-26"></a>

### 26. Magpie 读不到设置，或恢复设置失败

程序没能打开或保存原来的设置文件。

**相关报错：** 读取配置文件失败、无法访问配置位置、暂未能保留配置原件、暂未能完成配置恢复、恢复记录暂不可用

**检查步骤：**

1. Magpie 或设置文件放在 U 盘、移动硬盘上的，先把设备插好。
2. 文件正在网盘里下载或同步的，先等它完成；开着记事本修改这些文件的，先关闭记事本。
3. 重新打开 Magpie，试一次。原来的设置文件和备份都先留着。
4. 还不行，把 **logs 文件夹打包发来**。[怎么发，点这里](#feedback)。

<a id="error-27"></a>

### 27. 设置被恢复了，或变回默认了

程序已经尝试恢复设置。先看看平常用的效果还在不在。

**相关报错：** 已载入备份、已载入能够恢复的项目、已修复旧配置中的失效设置、原配置及备份均无法恢复、已生成默认设置

**检查步骤：**

1. 打开平常用的游戏或视频，试一下 Magpie。能正常用，就可以继续用。
2. 选中的效果组变了，就点 Magpie 左侧“默认”。给游戏单独建过配置的，就点那个游戏的配置。在“常规 → 效果组”里选回原来的名字。
3. 原来的组找不到，或者想找回旧设置，就把报错截图发来，说明“想找回原设置”。先保留原来的设置文件和备份。
4. 还不行，把 **logs 文件夹打包发来**。[怎么发，点这里](#feedback)。

<a id="error-28"></a>

### 28. 设置或参数存不下来

刚才的修改还没保存，直接关程序可能会丢掉。

**相关报错：** 最近的修改尚未保存到磁盘、参数尚未保存、配置保存失败、保存仍未完成

**检查步骤：**

1. **先保持 Magpie 打开，不要退出，也不要重启电脑。**
2. 点“主页 → 最近一次问题 → 查看详情”，再点“重试保存”。
3. 还失败就关闭正在修改设置文件的记事本。使用移动硬盘的插好硬盘，使用网盘同步的等同步完成，再点“重试保存”。
4. 看到“本次修改已保存到磁盘”就可以正常退出。仍失败，就保持程序打开，把想保留的设置截图。
5. 还不行，保持 Magpie 打开，把 **logs 文件夹打包发来**，附上刚才的截图。[怎么发，点这里](#feedback)。

<a id="error-29"></a>

### 29. 参数改了没生效，或一改就报错

这次参数没有成功用上。先把改动撤回，再试一次。

**相关报错：** HDR 组件参数无效、HDR 组件参数超出范围、此参数暂未应用到画面、本次更新未应用、实时参数应用失败、已恢复原档位

**检查步骤：**

1. [打开效果器的设置](#parameters)，把刚才改的数值改回原值，或调低一点。
2. 忘了原值，且改的是滑条，就双击那根滑条。已经提示“已恢复原档位”的，先保持现在的数值。
3. [停用效果后重新启用](#retry)，再试一次。反馈时说一下改的是哪个参数。
4. 还不行，把 **logs 文件夹打包发来**。[怎么发，点这里](#feedback)。

<a id="error-30"></a>

### 30. 改参数时，提示这次修改没有保存

程序或设置刚发生了变化，需要重新打开面板再改一次。

**相关报错：** 当前运行已更新，本次请求未保存、运行会话已变化、效果组或参数已在其他位置更新、本面板的修改未覆盖保存

**检查步骤：**

1. 把想设置的数值记下来，关掉参数面板。
2. [停用效果后重新启用](#retry)。
3. 重新打开参数面板，把需要的数值再改一次。这次只在这一个面板里调整。
4. 还不行，把 **logs 文件夹打包发来**。[怎么发，点这里](#feedback)。

2. 再点一次刚才的“导入”“导出”或选择文件夹按钮。

3. 还失败，在游戏画面设置里把分辨率调小一档；处理视频的，把播放器窗口拖小一些，再截图。
4. 还不行，把 **logs 文件夹打包发来**。[怎么发，点这里](#feedback)。

<a id="operations"></a>

## 不会操作时，看这里

用到哪一项，就看哪一项。

<a id="quit"></a>

### 怎么退出 Magpie

1. 看电脑右下角，找到 Magpie 图标。没看到时，先点小箭头“⌃”；把鼠标放在图标上停一下，可以看到名字。
2. 右键点 Magpie 图标，再点“退出”。

只点窗口右上角的“×”，Magpie 可能还在后台运行。

<a id="program-folder"></a>

### Magpie.exe 在哪里

打开你解压 Magpie 的文件夹，里面用来启动程序的文件就是 `Magpie.exe`。有的电脑只显示 `Magpie`，不显示后面的 `.exe`。

平常用桌面快捷方式打开的，右键点那个快捷方式，再点“打开文件所在的位置”。

<a id="profile"></a>

### 怎么打开这次出错的设置

1. 打开 Magpie，点左侧“主页”。
2. 找到“最近一次问题”，点“查看详情”。
3. 点“打开此配置”。接下来，就在打开的页面里找文中说的“捕获方式”“显示卡”等选项。

没有“打开此配置”按钮，就记下详情里的配置名，关掉详情，在左侧点同名的配置。名字也找不到，就把详情截图发来。

<a id="parameters"></a>

### 怎么找到效果组，怎么改参数

“效果组”就是你选的那套效果；展开后，里面的每一行就是一个“效果器”。

1. 点 Magpie 左侧“效果组”，找到正在使用的组，点开它。
2. 找到要改的那一行，把鼠标移到右边的按钮上，停一下。显示“参数”时，点这个按钮。
3. 在弹出的面板里，找到文中说的选项，改成要求的值。
4. 改完后，回到游戏或视频窗口，[重新启用效果](#retry)。

不知道正在用哪个组：[打开这次出错的设置](#profile)，看“常规 → 效果组”里选的名字，再回来找同名的组。

**删除一项：**先把这一项的名字和参数截图，再点**这一行右边**的垃圾桶按钮。不要点整个组旁边的垃圾桶。

**添加一项：**点**组底部**的“添加效果器”，在列表里选要添加的名字。

<a id="retry"></a>

### 怎么停用后重新启用

1. 点 Magpie“主页”，看“效果组快捷键”旁边写的是哪几个键。
2. 回到游戏或视频窗口。效果正在运行时，按一次这组键，先停用。
3. 点一下游戏或视频窗口，再按一次同样的键，重新启用。

“快捷键”就是同时按下的几个键。本文里的 **Win** 是键盘上带 Windows 标志的键。

<a id="unpack"></a>

### 怎么重新解压完整安装包

1. [退出 Magpie](#quit)，找到之前下载的 Magpie 完整压缩包。只有更新包的，回到原下载页面，下载完整包。
2. 右键点压缩包，选“全部解压缩”或解压软件里的“解压到”，选择一个新文件夹。原来的文件夹先留着。
3. 等解压完成，打开新文件夹里的 `Magpie.exe`。文件名也可能只显示 `Magpie`。
4. 在 Magpie 里选回之前用的效果组，再试一次。找不到原来的组，就先反馈，不用重新设置全部参数。

RTX 20 系、30 系使用 DLSSNR 的，还要按[下面的步骤换 DLL](#nr-dll)。

<a id="gpu-model"></a>

### 怎么看显卡型号

1. 同时按 **Ctrl + Shift + Esc**，打开任务管理器。
2. 点“性能”，再点“GPU”。看不到“性能”时，先点“详细信息”。
3. 右上方会写显卡名称，例如 **NVIDIA GeForce RTX 3060**。有“GPU 0”“GPU 1”的，分别点开看。

RTX 后面的数字以 **20、30、40、50** 开头，就分别是 20、30、40、50 系。例如 **RTX 3060 是 30 系，RTX 5070 是 50 系**。看不明白，就把这一页截图发来。

<a id="drivers"></a>

### 怎么更新显卡驱动

先看上面的显卡名称，只看与你显卡对应的那一段。安装完成后重启电脑，再打开 Magpie。

**NVIDIA 显卡**

1. 点 Windows“开始”，输入 `NVIDIA App`，打开它。没有装的，从[NVIDIA 官网](https://www.nvidia.cn/software/nvidia-app/)下载安装。
2. 点左侧“驱动程序”。有更新时，点“下载”，等下载完再点“安装”。
3. 使用 DLSSNR 的，再看已安装的驱动版本，必须是 **615 或以上**。已经提示最新，但数字仍低于 615，就把这个页面截图反馈。

“自动调优”在 NVIDIA App 的“系统 → 性能”里。文中要求关闭时，把它的开关关掉即可。按钮位置也可看[NVIDIA 官方图解](https://www.nvidia.cn/geforce/news/gfecnt/202411/nvidia-app-download-and-features/)。

**AMD 显卡**

1. 打开[AMD 官方下载页面](https://www.amd.com/zh-cn/support/download/drivers.html)，点“下载 Windows 驱动程序”。
2. 打开下载的文件，等它检测显卡，再按提示安装显卡驱动。拿不准该选哪一项，就把页面截图反馈。

**Intel 显卡**

1. 打开[Intel 驱动程序和支持助理](https://www.intel.cn/content/www/cn/zh/support/detect.html)页面，下载并安装这个工具。
2. 打开工具，安装它找到的显卡驱动更新。工具没有找到更新，或提示无法安装，就把页面截图反馈。

<a id="nr-dll"></a>

### RTX 20 系、30 系：DLSSNR 的 DLL 怎么换

DLL 就是下面要复制的那个文件。RTX 40 系、50 系用完整安装包自带的文件即可。

1. [退出 Magpie](#quit)。解压 `DLSSNR-DLL-Options-310.8.0.0.zip`，打开里面的 `SF-v2` 文件夹。
2. [打开 Magpie 程序文件夹](#program-folder)，把原来的 `nvngx_dlssnr.dll` 复制一份到桌面，留作备份。
3. 回到 `SF-v2` 文件夹，右键点 `nvngx_dlssnr.dll`，选“复制”。
4. 回到 Magpie 程序文件夹，在空白处右键点“粘贴”。提示同名文件时，选择替换。这个文件要和 `Magpie.exe` 放在一起。

<a id="feedback"></a>

## 做完还是不行：把 logs 发来

**logs 是 Magpie 自动记录问题的文件夹。你不用看里面写了什么，直接把文件发来就行。**

1. [打开这次报错的 Magpie 程序文件夹](#program-folder)，找到名字叫 **logs** 的文件夹。
2. 右键点 **logs**，选“压缩为 ZIP 文件”。没有这个选项，就点“显示更多选项 → 发送到 → 压缩(zipped)文件夹”；Windows 10 可直接找“发送到”。
3. 等打包完成，把生成的 **logs.zip** 作为附件发来，再附上一张报错截图。
4. 写一句你刚才做了什么。例如：**“我在播放器里开 DLSSNR，提示仅透传。按指南试完了，还是不行。”**

不会截图：同时按 **Win + Shift + S**，用鼠标框住报错。回到反馈页面，按 **Ctrl + V** 粘贴。

找不到 logs：打开 Magpie“主页 → 最近一次问题 → 查看详情”，点“打开日志目录”。文件夹打开后，按 **Alt + ↑** 回到上一层，就能选中 logs 文件夹来打包。

程序打不开，或者仍找不到 logs，就先发报错截图，说明“程序打不开”或“找不到 logs”。**如果报的是保存失败，发日志时先保持 Magpie 打开。**

反馈入口：[Magpie 问题反馈](https://github.com/SAOG0721/Magpie/issues)。
