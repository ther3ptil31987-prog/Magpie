## 已实现行为

RTSS 状态保留独立标题，说明按配置对象、版本、操作结果、当前 FPS、具体错误、事实提示排列。每段作为 `WrapPanel` 的一个子项测量，当前行放不下时整段移到下一行；超长段由自己的 `TextBlock` 在整行宽度内换行。分隔符与后段一起测量，用不换行空格连接，避免单独占行。全局共用上限的事实提示移入同一说明区域。未安装时省略配置对象，工具不可用时不再沿用旧预览的 FPS。

状态右侧按“初始化 Magpie → 启动工具 → 重新检测”排列，三个入口使用同一个普通按钮样式：默认按钮模板、12 DIP 字号、32 DIP 最小高度、零边框、中性填充及主题交互反馈。启动工具保留两个独立菜单项，按钮区域按内容宽度换行；其他输入与下拉仍使用 225 DIP 的共享列。

初始化是独立命令，只有点击才执行，不受当前游戏管理范围和停止策略影响。worker 核对实际程序文件名，只允许 `Magpie.exe`，不能写 Global 或所选游戏。缺失配置从 Global 内容创建；已有配置只清除 `[Framerate]` 的 `Limit`、`LimitTime`，分母、检测、OSD、其他字段及其字节表达保持原样。已有独立配置的两种限制均为零时，直接返回“已不限帧”，不调用 setter、SaveProfile、UpdateProfiles，也不替换文件。

初始化结果明确标注 Magpie.exe，与游戏会话状态区分。命令运行在既有串行 worker 上，处理中更新按钮文字并禁止重复操作。初始化不改变游戏的 original、lastWritten、created、同步目标或退出策略；后续游戏同步和停止仍使用原来的事务。

## 帧时间清零与文件事务

本机 RTSS 7.3.5.28314 拒绝 `FrametimeLimit=0` setter。本次初始化使用明确的字段清零入口，在此已验证版本上保留原文件结构并写入两个零值；不从任意 SDK 失败转入整份文件回退。其他版本需要写入时报告格式尚未支持；已不限帧的只读结果不需要该写入入口。

解析保留原大小写、空白、注释、节顺序、ANSI 兼容字节、UTF-8 BOM 和换行。缺失的两个限制字段按节位置补入；重复字段、重复限帧节、UTF-16、无效分母和超过 1 MiB 的输入被拒绝。格式测试与 RTSS API 实际读回分别校验。

候选文件在同目录创建、完成写入并刷新后，再核对快照的完整内容和物理文件身份。已有配置使用带备份的文件替换；新配置使用禁止覆盖的移动，并在创建期间锁定继承来源 Global，防止来源变化。微软的 [ReplaceFileW 文档](https://learn.microsoft.com/en-us/windows/win32/api/winbase/nf-winbase-replacefilew)规定了备份和部分失败语义；替换前检查与提交之间仍可能发生外部编辑。

实现核对实际被替换的备份内容与身份。如果替换窗口内发生编辑，仅在目标被独占写入锁保护且内容仍等于本次输出时回退到实际被替换版本；后续外部编辑保留，未能回退的备份路径写入诊断日志。部分替换失败只恢复缺失的目标路径，不覆盖外部新建目标。随后读回磁盘和 SDK，验证两种限制归零、分母和其他内容一致，再请求 UpdateProfiles。写入、读回、重载及接口异常分别记录。

此路径只用于 Magpie 不限帧初始化。Global/游戏的非零帧时间转正 FPS，以及停止时恢复缺失字段的完整表达，仍属于保存失败 TODO 的 C01。

## 默认管理员启动

`IsAlwaysRunAsAdmin` 的新默认为 true。旧配置缺少 `adminStartupDefaultsVersion` 标记时，一次性迁移为 true；标记写入后保留用户后续选择，包括主动关闭该设置。正常读取和升级迁移均在原设置路径中完成，不改变用户配置目录或 RTSS ACL。

普通实例读取启动偏好后，复用原有 runas 重启；配置迁移持久化和原配置保护由管理员替代实例完成，避免先在只读便携目录保存。已经提权或用户之后选择关闭管理员启动时直接继续。取消 UAC 或启动失败记录实际错误并结束该次启动，不重复弹出授权。

原重启链路保留命令行，先释放快捷键和互斥再启动替代实例。旧自启动任务在提升权限后按独立版本标记更新；任务注册失败保留未迁移状态。源码核对包括托盘启动参数、计划任务权限、普通应用重启和更新器的 open 启动入口。管理员启动不会自动初始化 Magpie 配置或启动 RTSS/MSI Afterburner。
