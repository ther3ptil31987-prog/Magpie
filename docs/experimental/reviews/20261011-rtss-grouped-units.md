## 实现和原因

- **模式切换外框。** 已核对本机 Windows SDK 10.0.26100.0 的默认 ListBox 模板：`LayoutRoot` 只绑定 Background / BorderBrush / BorderThickness，不绑定 CornerRadius，原页面赋值不会使其绘制圆角。现在由页面局部 Border 实际绘制 6 DIP 外框，原生 ListBox 透明且无边框；保留 4 DIP 主题选中项、单选绑定、键盘、焦点、高对比度资源及旁边的恢复默认按钮。没有替换 ListBox 的选择机制或全局模板。
- **10 处数字单位外置。** 数字输入本身恢复原生背景、边框和状态模板；移除原先跨数字与单位的装饰边框。FPS / px / x 位于相邻独立列，与输入框间隔 8 DIP，单位槽 28 DIP。普通数值区 116 = 输入框 80 + 间距 8 + 单位 28；裁剪单项 136 = 输入框 100 + 间距 8 + 单位 28。复合参数列仍为 280，裁剪仍两列，原窄窗口换行和按条件整体隐藏机制继续生效。原有数值范围、格式器、编辑、清除、键盘调节、右键菜单和双向绑定保持。
- **RTSS 按职责独立成组。** 顺序变为帧率控制 → RTSS 配置接管 → 静态画面 → 光标刷新（仅高级）→ VRR。简单模式共四组，高级五组。帧率控制保留内容和节奏；RTSS 组使用系统链接图标及原生展开器，包含简单同步开关 / 高级目标限帧、作用范围、停止策略，再接共用联动状态和管理。每行仍直接使用 SettingsCard，共用表面、分隔线和 280 DIP 参数列。
- **状态与管理。** 固定的“RTSS 配置接管”成为组标题；其下状态行直接显示实际标题、说明、图标 / 忙碌提示和获取 / 重试。管理正常默认收起，关闭联动和跟随源时也能打开。详情按 RTSS 程序 → Magpie 配置 → 可选 MSI Afterburner 顺序呈现；对应检测 / 启动、初始化、启动操作保持原能力与忙碌条件。管理结果不覆盖目标联动状态。只有 `ShowRtssManagement()` 的呈现可见性变为始终可用，RTSS 服务、保存模型、自动准备 / 重试 / 恢复流程均未修改。
- **文案。** 20 种语言资源将目标限帧行的功能说明移至 RTSS 组标题，避免重复；更新内容处理组说明及简单同步说明，明确停止后恢复。新增说明内容提供简体、繁体和英语，其余沿用英语回退；移动的 RTSS 功能说明保留原翻译。
