## 源码行为

- 在“帧率与刷新”增加“NVIDIA G-SYNC 前台兼容（实验）”，保存为 `frameRefresh.nvidiaForegroundCompatibilityEnabled`，默认关闭、重启缩放应用。偏好可独立保存，标准 VRR 关闭时运行不生效；重置、类型修复和过期参数面板的字段合并均接入。英文、简体、繁体资源已添加。
- `Win32Helper::GetRealForegroundWindow()` 是业务统一入口。捕获、源跟踪、参数／IME、启动停止、快捷键、通知和层级判断均绕过本原型的进程 API detour，取得原始返回值。
- `NvidiaForegroundCompatibility` 只在 NVIDIA 呈现适配器、单输出无边框 DXGI、无 FG 且标准 tearing 路径有效时允许覆盖。每次目标查询仍检查真实前台、source capture／root 身份与输出身份；源 popup、参数宿主、无关应用或 NULL 前台均保留真实值。UWP capture／root 的不同 PID 不会被简化成一个 PID 判断。
- 第一版候选范围是已加载的 `nvwgf2umx.dll`、`nvwgf2um.dll`、`nvldumdx.dll`、`dxgi.dll`、`d3d11.dll`；地址范围由模块快照取得并固定模块寿命，未知调用保留真实值。范围内的实际 API 命中才计入 `targetQueries`，实际替换返回才计入 `appliedQueries`。这是候选筛选，尚未证明这些模块在本机消费 G-SYNC 前台身份；调用经其他模块转接时可能未覆盖。
- 读取会话快照使用原子字发布及 generation 复核，读取失败直接回真实值，避免等待前端线程。异步驱动线程可以读取相同有效上下文，不依靠只围住 Present 的 TLS；TLS 仅供真实业务查询绕过与防重入。
- 输出 HWND 创建后先建立准备上下文；device 初始化前启用来源记录，实际 NVIDIA device 与 tearing／输出资格确认后才允许覆盖。因此 device 初始化阶段可能只被记录，不能声称已经改变了更早的驱动缓存判断。交换链创建及首次／稳定 Present 的覆盖与阶段记录已接线，早期缓存问题仍需对照结果判断。
- 切屏通过实时真实前台直接使返回覆盖失效；参数编辑／焦点交接额外暂停。停止、隐藏或重建先退休并发布无效上下文，再切断 owner、释放输入及等待后台清理；最后只禁用本原型的 API target。保留一个固定 trampoline 到进程结束，避免其他线程仍持有原始入口时释放可执行内存。
- 安装、启用或呈现失败锁定本会话回退；禁用失败时已退休的上下文继续直通。没有无差别操作全部 Hook，没有拦截失焦／IME 消息或 `SetCursorPos`，没有向源游戏注入或设置持续还焦点。外部工具已修改同一 API 的情况尚未验证，受控对照须排除这类工具；原型的真实通道保证限定为它自身安装的 Hook。
- 沿用现有缓冲、flags、Resize、普通 DXGI 有界回退及 SDK 单次提交。日志用 `initializing` 区分初始化待完成，首次 Present 记录真实前台；兼容日志独立记录请求、安装、资格、调用模块／线程／前端阶段、真实／返回身份，`active=unknown` 不随开关变成 true。采样有界、低频汇总，不在 detour 中解析模块或刷文本日志。

## A／B／C 对照入口

使用同一构建候选、单屏 SDR、无 FG、相同标准 VRR flags、内容场景与最终提交预算。启动前退出已有 Magpie，保证新进程继承诊断环境变量；本轮没有运行下面任何入口。

| 组别 | 兼容开关 | `MAGPIE_GSYNC_DIAGNOSTIC` | 行为 |
| --- | --- | --- | --- |
| A | 关闭 | 删除 | 标准 VRR，源真实前台 |
| A 的来源记录 | 关闭 | `trace` | API 返回保持真实，只记录候选及有限未知来源 |
| B | 关闭 | `reference` | 首帧显示后尝试让输出持有真实前台，前端计时目标 10 秒 |
| C | 开启 | 删除 | 源真实前台，目标模块查询可见输出 HWND |

PowerShell 环境变量操作：

```powershell
$env:MAGPIE_GSYNC_DIAGNOSTIC = 'trace'     # 或 reference
& $candidateExe                         # 构建会话提供候选 EXE 路径
Remove-Item Env:MAGPIE_GSYNC_DIAGNOSTIC -ErrorAction SilentlyContinue
```

B 保留交换链合同，暂时允许输出通过自动还焦点及 3D 前台检查，并保持基线层级；关闭时只有输出仍真实前台且原源身份有效才归还。Alt+Tab 到其他程序不会被抢回；停止先退休，owner 已切断后才执行参考组还焦点。计时由前端消息／轮询驱动，前端阻塞时不是硬实时的 10 秒保证。必须从日志核对输出确实获得并保持前台、源捕获是否继续、PresentMode 是否变化；请求激活失败或源失焦暂停时不能算有效 B。日常 C 模式不使用真实抢焦点。

`targetQueries=0` 表示本候选范围没有收到查询，不能写成“已验证入口但无效”；`appliedQueries>0` 表示覆盖执行过，仍不是 G-SYNC 开启证明。记录按候选模块／前端阶段去重，每阶段最多收录一个未知来源，不是穷尽调用栈的跟踪器。NVIDIA 指示器、显示器实时 Hz／LFC 与最终显示事件仍需一起验证。
