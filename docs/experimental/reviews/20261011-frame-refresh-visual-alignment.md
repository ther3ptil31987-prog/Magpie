## 已修改

- 内容、空闲重绘、RTSS 指定上限、光标补充率共用“模式 + 条件数值 + FPS”的同行结构。模式和数值各占 172 DIP，两者间距 8 DIP；数值组包含单位及原生增减按钮。使用 WrapPanel、局部卡片换行阈值与原生下拉文本换行，先将整组输入移到标签下方，再按可用空间换行。跟随源、关闭和光标自动收起数值组，不保留空白附属行。保留字号、15–360 范围与原绑定。
- 四组使用原生 PathIcon：帧率表、重绘、指针、显示器。光标策略移入第三组内容行。标题右侧为简单/高级并列单选，恢复默认紧邻其右侧，简单 / 高级均可见；窄标题区将操作组整体移到下一行。高级重置范围沿用原实现。追加的简单模式重置仅恢复可见字段：内容自定义 60 FPS、空闲启用 30 FPS、VRR 和同步限帧关闭；保留高级偏好、当前模式及其他应用配置，不改外部 RTSS。
- RTSS 主区域改为左侧图标/忙碌指示、独立标题与次级说明，右侧按状态显示获取或重试；下方原生 Expander 提供行内管理。管理分别展示 RTSS 程序、Magpie 配置和手动操作结果，保留重新检测、初始化、RTSS / Afterburner 启动入口。
- 主状态依据当前有效会话的实际策略；待重启的设置不能伪装成已生效。无当前会话且关闭联动时明确显示“RTSS 联动未开启”。失败保留具体原因、部分保存和恢复失败；“缩放继续运行”仅在当前关联会话且 ScalingService 实际缩放时出现。
- 当前目标、工具清单、手动管理结果独立保存。自动准备进度属于目标会话；手动自身初始化和可选工具结果只进入管理详情。未执行工具检测的等待状态不能清空已观察到的工具清单。工具启动完成使用明确事件结果，之后退出不倒推成“启动失败”。
- 重新检测仅检测程序、读取自身配置并执行只读健康检查，不调用 Retry、不启动工具、不写限帧配置。检测到后来安装/启动的 RTSS 后，显示可以重试，而不是继续声称依赖缺失或直接声称目标已就绪。重试仍针对当前有效会话；代次、身份、取消及外部冲突保护保留。
- 新增资源在 20 个语言文件中键一致；简体、繁体、英语有对应文本，其他语言的新项沿用英语回退。旧的菜单/拼接字符串 UI 断言已替换，资源测试改为覆盖当前标题、说明和管理结果。
