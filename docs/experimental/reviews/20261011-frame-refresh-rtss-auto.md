- 全局模式默认简单。设置页标题旁切换模式；简单为帧率控制、静态画面、可变刷新率三块，高级增加第三块光标刷新，VRR 位于第四块。简单不显示光标策略或只读说明。
- 内容帧率、空闲重绘、VRR 共用保存值。简单运行策略为 Front Edge、原始帧优先并补充；固定内容 N 时补充 N，跟随源时补充 60 FPS。高级光标与节奏偏好不被投影覆盖。
- 新配置、缺省/无效字段和恢复默认的全局重复帧检测为 Never；已有显式 Always/Dynamic 保留。效果内部的 `duplicateFrameFiltering` 未改变。
- `rtss.simpleContentSync` 是单独保存的简单模式开关，缺省 false，沿用未启用前不接管的行为。启用后有效范围为当前目标、同步内容帧率、结束时恢复；高级 scope/rateMode/customRate/exitPolicy 保留。内容跟随源时等待固定目标，不猜测 RTSS 上限。
- 高级 RTSS 合并为不接管/同步/指定选择；附属范围和结束策略按需显示。两项使用同一原生 ComboBox 样式，标签和输入分别共用 Grid 行，保证长标签与控件基线对齐；可用宽度小于 560 DIP 时改为纵排。保留原字体、主题、焦点和选项语义。
- 删除原常驻的约束说明区。状态区域保留实际错误、保存结果、配置限帧值与必要操作；管理菜单收纳重新检测、自身配置初始化和两种工具启动入口。
- 工具栏没有模式选择，简单会话可编辑共享 VRR。模式、RTSS 或全局重复检测变化会标记待重启；保存并重启时重建相应会话策略。普通效果/内容编辑保留既有参数重启路径和事务合并。

## RTSS 生命周期

串行 worker 在有效会话获得固定限帧目标后检查依赖，按需启动 RTSS，初始化当前实际 Magpie 可执行文件自己的不限帧配置，再应用目标限帧。启动采用最长 10 秒的有界等待，每 250 ms 检查取消；不会阻塞 UI 或渲染线程。已运行/已不限帧的状态直接复用，MSI Afterburner 是可选入口，不作为依赖。

未安装时显示获取 RTSS 的链接；没有自动下载或安装。准备失败时只暂停 RTSS 管理，缩放继续，手动重试针对当前会话身份。重复内容通知不反复排队写配置。每 2 秒的后台健康检查只读取已成功接管会话的进程状态；RTSS 退出后等待用户重试，不循环自动启动。

取消、停止、换会话均检查身份、代次与目标进程。旧任务不能向新会话发布状态；文件提交继续使用原事务校验。已保存但重载失败时保留部分完成事实；重试执行缺失的重载，不以读回相同数值冒充成功。停止按会话启动时的退出策略恢复或保留，不退出外部工具、不清除不属于本会话的配置。外部冲突仍保留原来的暂停和保护规则。
