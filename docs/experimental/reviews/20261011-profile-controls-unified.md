## 实现

- `ProfilePage` 的常规、窗口模式、性能、帧率与刷新、源窗口、光标、原有高级共用 280 DIP 参数列。展开器独立保留原生 32 DIP 箭头命中区；普通行及展开子项使用相同的参数右边线。渲染显卡位置、原有分组和所有动态可见性保持。
- 六处“模式 + 数值”复合编辑器（四处帧率、窗口倍率、光标倍率）共享布局：常规宽度为 156 + 8 + 116；数值隐藏后模式框占满整列。可用空间不足时整组移到标题下，再将模式与数值换行。修正两处倍率回调，不再写回旧的 200 DIP 最小宽度。
- 10 个数字输入保留原生 NumberBox、绑定、范围、格式器与校验，仅隐藏可见步进按钮。FPS / x / px 放在组合框的单位尾部；保留 `ControlHelper` 设置的右键菜单及原生编辑行为。原生清除按钮使用固定 24 DIP 槽和零内边距，避免聚焦时挤动文本；数字框本身和边框不叠加额外高度。没有修改 ViewModel 数值提交策略。
- 自定义裁剪四值组成两列，每项 136 DIP，按左 / 右、上 / 下排列，窄宽度换成单列。保留浮点精度、最小值和启用条件，并添加独立可访问名称。光标隐藏延迟的滑杆与 52 DIP 读数共用 280 DIP；启动参数成为标签下的扩展输入行。
- 帧率组四个图标换成与相邻设置相同的系统 FontIcon。模式选择保留原生 ListBox 单选、键盘选择与全局绑定，增加局部中性表面、圆角和短强调线；覆盖选中、失焦选中、悬停、按下及禁用状态。恢复默认继续在模式右侧，两种模式均可用。
- RTSS 使用固定标题“RTSS 配置接管”，其下保留独立的实际状态和说明、忙碌标记及读屏通知。状态行和管理详情全部成为帧率控制展开器的直接 SettingsCard 子项，沿用组内表面与分隔线，移除独立深色管理面板。
- 管理入口与按状态出现的获取 / 重试同列；原生 ToggleButton 使用普通按钮的中性选中颜色，并提供展开箭头和本地化读屏说明。程序行对应重新检测 / 启动 RTSS，Magpie 配置行对应初始化，可选 Afterburner 独立成行；单按钮 136、双按钮 280。内层 WrapPanel 按自然宽度右对齐，单个按钮不会落在参数列左端。原有能力判断、管理结果和会话状态来源均未更改。
- 新增 19 个界面 / 可访问性资源键，在 20 个语言文件中补齐。新增 RTSS 文案提供简体、繁体、英语，其他语言英语回退；裁剪与倍率标签复用已有翻译。

共用控件仅有一项修正：`SettingsExpander.Resource.xaml` 的内层标题卡片改为绑定展开器本身的 `Padding`，使 ProfilePage 的局部内边距生效。默认样式值仍为原 `16,16,4,16`；其他页面未采用新的参数列或控件样式。
