## 本机只读探测与实现选择

本机 RTSS 为 7.3.5.28314。本次通过独立 Python 进程调用用户安装的 `RTSSHooks64.dll`，只执行 Load/Get：`FramerateLimit`、`FramerateLimitDenominator`、`FrametimeLimit`、`AppDetectionLevel` 的 4 字节读取成功；`FrametimeLimitDenominator` 不支持此属性名。第一次探测的 Global/Magpie 文件哈希未改变，后续只读检查确认 Profiles 下 4 个文件的哈希未改变。没有执行 Save、Set、Delete、Update 或工具启动。

按 SDK 声明尝试 `EnumProfiles` 时，空缓冲与非空缓冲调用均发生访问异常；没有据此推断所有版本行为或故障原因。产品源码改用安装目录内配置文件的存在性检查，不再调用该导出。其他公开接口使用独立的 SEH 边界；发生原生接口异常后停止调用该模块，避免拖垮缩放。该保护尚未编译或运行测试。

帧时间分母从原文件保存，当前 SDK 无可用的对应属性。恢复前确认其仍与原值一致，否则报告失败，结束尝试；不静默改文件。若 SDK 保存改变了原本缺失字段的表达形式，也不会把近似恢复标为精确成功。
