工作树：`worktrees/dlssnr-error-guidance`。本轮仅实施、源码 review 和无需编译的验证。没有调用编译器、构建/发布/部署脚本，没有修改版本号或用户运行配置，没有合并其他功能分支。提交以该功能分支最新提交为准。

## 已实施

- DLSSNR 状态独立于参数可调性：未运行、启动中、成功处理后运行中、单层跳过、多层停止。主页及浮层显示持续状态；历史诊断继续使用 `last-issue.json`。
- 使用带锁的用户会话快照及 renderer 代次隔离更新；停止后拒绝更新；重复状态不逐帧通知。只有成功 Draw 且后端健康才转为运行中。
- 初始化、运行及尺寸重建失败传递结构化阶段、操作、原因、原始码类型/数值和结果。`FeatureNotSupported`、`OutOfDate` 保留其多种可能含义。
- 区分非 NVIDIA 选卡、确认文件缺失、加载失败、导出缺失、组合不支持、驱动/功能库版本要求、内存/访问失败、进程保护和未知失败。不增加未验证的 NVIDIA 型号或最低驱动规则。
- 诊断包含实际渲染 GPU 名称/PCI ID/子系统/LUID、Windows 驱动文件版本、初始化输入输出尺寸/格式、请求 DLL 的磁盘路径/文件版本，以及可取得的实际加载模块路径/版本。原始失败保留，不用清理错误替代。
- 详情将主要操作放在长诊断之前；按原因选择程序目录、对应配置、恢复说明或效果组。保留复制诊断、日志入口，打开失败显示路径。完整说明在后续打包时复制到程序目录，本轮没有运行打包。
- 效果组/效果器使用会话内身份与名称、顺序共同校验，删除重建、重排同名实例或复制组不会复用诊断目标。变化时给出列表提示。运行身份不写入配置文件。
- 窗口权限查询失败独立于真实高权限窗口，保留 Beta8 的 GameGuard 窗口身份恢复路径。
- 新增开发规范、恢复说明，更新既有中文指南的 DLSSNR 章节、TODO 和测试矩阵。简中、繁中、英文提供本次文案；其他资源文件对新增键使用英文回退，不声称完成这些语言的翻译。

## Review 与修正

本轮采用源码自查，没有启动子代理。沿后端失败 → renderer 降级/停止 → 会话快照 → UI/诊断 → 操作目标逐段检查。

| Review 关注点 | 处理结果 |
| --- | --- |
| 多层停止仍使用“画面继续”文案 | 增加停止错误码（追加，保留旧 MP 编号），状态结果与停止分支一致 |
| HDR 限制误报未初始化 | 增加正常受限模式、标记及具体说明，后端故障单独判断 |
| 单层失败后参数仍显示实时生效 | UI 使用当前失败状态禁用；已排队编辑走原有拒绝/回退流程，不静默丢弃或覆盖首次诊断 |
| 停止/重建后异步状态晚到 | 会话对象和 renderer 代次双重校验；停止状态拒绝后续写入，旧析构不关闭新代次 |
| 失败信息因临时后端析构而丢失 | 失败在析构前复制；共享 snippet 初始化结果和后续 pass 原始码向上传递 |
| 同名实例、删除重建、复制组误定位 | 增加运行身份，复制组及其效果分配新身份；页面延迟加载后重新验证目标 |
| 长诊断与多操作按钮溢出 | 操作置前，内容区可滚动；仍需真实 DPI/多语言界面验收 |
| NGX 保护码类型混淆 | 区分异常码与 shutdown 保护产生的 Win32 状态；不把 NGX 数值作 Win32 建议 |

其他高频类别也核对了现有路径：捕获失败已按当前捕获方式选择建议；补帧初始化失败和运行时关闭已有不同错误；原生初始化保留格式/显卡/原始日志，新增 PCI 标识有助于避免只凭显示名称判断；效果资源错误保留原编号和诊断。未发现足够依据需要在这些类别中新增硬件判定，未改动其渲染策略。权限误分类已实施修正；同样发现 VFX TrueHDR、RTX Video HDR/降噪对不适用参数返回 `Unavailable`，已归为 `Restricted`，避免正常参数限制被误报为后端故障。
