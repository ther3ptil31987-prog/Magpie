# RTSS 按操作判断能力整改

日期：2026-10-09。分支：`feature/069-rtss-target-frame-rate`。开发基线：`381d8f45`，原功能实现为 `369db4e2`。能力整改 TODO 第一阶段 10 项已完成源码及隔离回归，第二阶段 4 项后置；产品构建、部署、原生页面和目标 FPS 交给独立会话。

RTSS 版本号仅用于显示和诊断。初始化、读取、整数限帧及停止处理按当前操作所需能力执行；缺少某项能力不再拒绝其他具备条件的操作。开始限帧不要求保证未来恢复成功。

## 操作依赖与实际行为

| 操作 | 必需条件 | 不再统一要求 |
| --- | --- | --- |
| 读取配置 | 可加载的匹配架构模块、Load/Get、可读目录；字段按实际 getter 或明确磁盘内容读取 | Save、Set、Delete、Update、运行状态和全部 getter 成功 |
| Global/已有目标整数限帧 | Load/Get/Set/Save/Update、RTSS 运行；实际改变的字段具备 setter 接受与 API/磁盘读回能力，落盘核对通过 | Delete、未来恢复保证及可选检测查询 |
| 新建目标限帧 | 同上；Low 的设置或可靠的已知 Low 值，创建与读回通过 | 预先要求 Delete 或恢复必定成功 |
| 自身不限帧初始化 | 可信当前程序名称、Load/Get、可处理的字段结构、文件权限、竞争检查及读回；运行时需要 Update，已不限帧只读返回 | 精确版本、固定 Magpie.exe、Save/Set/Delete；离线时不调用 Update |
| 恢复已有配置 | 当前写入所有权、已知原表达、Load/Get/Set/Save；运行时调用 Update | 这些恢复条件不作为开始限帧的前提 |
| 撤销新建配置 | 当前完整内容仍属本次写入，Load/Get/Delete、删除读回；运行时调用 Update | Save/Set；缺 Delete 只使本次停止恢复失败 |

初始化仍采用明确的限帧字段文件路径，不是普通 Apply/Restore 失败后的任意文件回退。Global/目标非零帧时间转正 FPS，以及 SDK 补齐原缺失字段后的精确恢复，继续属于保存失败 C01。

每次准备操作重新确认工具运行状态及当前模块的操作能力。状态发布和预览完成时重新取能力，异常模块立即撤销可用标志；原有异常模块隔离保留。已修改会话绑定开始写入的安装目录，后续同步或停止不会把旧快照写入其他安装。

### 未知信息与已知的不变字段

快照新增各限帧字段和检测级别的已知标志。getter 不提供某字段时，明确存在的有效磁盘值仍可读取；磁盘字段省略且 getter 不可用时保留未知，不把它显示为 0、检测关闭或默认分母。

设置规则先读取本次属性，查询不可用时使用快照中已知的值判断是否需要修改；未知值不当作 0。需要修改时尝试用户请求的 setter，实际拒绝仍失败。getter 可用则立即核对返回值；getter 不提供值时，依赖授权保存后的明确磁盘字段完成读回。保存结果缺失、不可读或与请求不同仍失败，setter 返回成功本身不算保存成功。写入前的竞争比较核对文件身份、字节及双方都已知的值，可选信息变为未知不冒充外部编辑；未改字段以原字节或字段内容核对保留。缺少可选检测查询不阻断已有配置限帧，其他设置继续核对保留。

恢复不会猜测未知原 FPS、分母或必要的帧时间表达；未知原值只在停止时使该次恢复失败，不阻断原本可完成的开始操作。恢复只尝试一次，不修改用户的保留/恢复策略，不安排下次启动补偿。

## 自身名称与会话身份

自身配置由当前运行程序的真实路径取得名称，并在配置访问模块内绑定。改名程序使用自身实际名称；不能把初始化参数重定向到 Global、游戏或旧产品名。合法 exe 名称、无损 ANSI 转换和目标 HWND/PID/创建时间检查保留。

目标解析只按进程身份排除自身，不再额外排除固定 Magpie.exe 名称。另一个进程若与自身共用同一个 exe 配置名，会单独报告同名配置冲突；游戏限帧和自身不限帧不能独立配置。初始化与游戏会话快照、同步和停止策略仍独立。

## 状态与偏好

读取、开始限帧和初始化各自记录可用能力，移除单一 accessReady。RTSS 未运行时仍可预览或尝试持久初始化；目标限帧等待运行。停止或取消后的旧请求不会因启动工具重新应用。

状态沿用同段分段换行，数值标为“配置限帧”，区分配置结果、RTSS 未运行及已请求重载。重载导出返回后显示“已请求重载配置”；导出为 void，不能由返回推断目标实测 FPS。已经核对落盘而重载失败时保留“配置已保存”和具体错误两段，不混同写入失败。缺接口、对象、格式、架构、权限和重载分别使用简短原因，20 份资源一致。

同步模式忽略未使用手动值的损坏，局部恢复该值到 60，保留范围、同步及停止策略；再次保存不会重置整份 RTSS 偏好。实际使用的手动值无效或操作枚举未知时仍停止外部写入。15–360 手动范围与 1000 内部范围保持原实现，数值范围核实属于后置 T10。
