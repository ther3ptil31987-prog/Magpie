# RTSS 界面调整与同步帧率显示

日期：2026-10-09。分支：`feature/069-rtss-target-frame-rate`，起点 `ae03254c`。按[界面 TODO](../todos/20261009-rtss-ui-text-and-style-TODO.md)完成本轮源码和隔离回归，产品构建、原生界面及部署由独立会话执行。

## 界面与设置

RTSS 区域保持管理范围、状态、帧率设置、限制帧率、停止处理的固定行顺序。“停止缩放后的处理”直接位于限制帧率下方，采用外层展开区的同级 SettingsCard 样式。不再提供 RTSS 内层高级选项，整个刷新分组原有的高级选项保持原位置。

“与内容帧率同步”选项采用新名称。同步模式保留限制帧率行，禁用数值编辑并显示当前会话解析后的整数目标；未开始、已停止、跟随源或没有有效目标时显示“—”。手动值独立保存，切回自定义恢复原值及 15–360 FPS 输入范围；同步解析的 1–1000 FPS 不受该手动范围裁剪。不管理 RTSS 时，帧率和停止策略行仍可见并禁用。

20 份资源文件的状态和失败文字已精简。简体中文使用“配置已更新”“恢复失败”等结果，保留全局共用、独立配置及检测关闭的简短事实提示；英文与其余语言现有英文回退同步更新。移除 3 个废弃资源键，为只读同步输入补齐可访问名称。

## 同步显示与会话

手动编辑框与只读同步框占用同一个 Grid 单元格，复用同一 NumberBox 样式，模式切换只更换数值呈现。同步属性只有 getter，使用 OneWay 绑定；未知值返回 NaN，由 NumberBox 的占位文字显示“—”。显示刷新没有保存偏好或调用 RTSS 写入的路径。手动 setter 也忽略同步或不管理状态下的迟到回调。

`RtssService::ContentSyncRate` 只读取当前 UI 会话的解析目标，并核对配置身份、捕获的同步模式及取消状态，不依赖可能保留停止结果的状态快照。解析目标改变和停止时通知界面；停止没有发生写入时也会刷新占位。该查询不调用 RTSS API，不改变原有写入、恢复、冲突或停止策略捕获规则。
