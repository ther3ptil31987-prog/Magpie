# 0.6.10 统一 VRR、FG 与前台关联源码交接

日期：2026-10-05（Asia/Shanghai）。分支：`feature/069-vrr-gsync`。对应 [实施 TODO](../todos/20261004-v0.6.10-vrr-unified-fg-foreground-TODO.md)。本轮按用户要求继续原功能分支，源码与静态检查已完成；编译、部署和硬件测试交由独立会话。

## 基线与范围

合并提交 `37533b2f` 引入已部署 Beta2 的 `96cd7b8a` 基线，保留原生 DWORD 修复、参数焦点／owner 协调、渲染显卡选择及其测试修正。合并冲突仅位于文档索引，保留两边有效记录。未修改主工作树、发布包、运行配置、标签或远端。

Beta2 用户反馈是双开关无 FG 有指示器，DLSS／XeSS FG 均失效，点击 Magpie 主界面可恢复。部署日志确认共同 `!frameGeneration` 门控。本轮解除该门控并完成统一入口；本次源码还没有对应的运行结果。按用户约定，后续功能验收以最终输出的 G-SYNC 指示器为准。

## 实现结果

### 统一产品入口

配置文件 → 帧率与刷新 → 高级选项，首项为 **VRR 可变刷新率**，下一项为重复帧检测。描述为“让显示器刷新率跟随输出帧率，提升画面流畅度。”。删除原 NVIDIA 前台兼容卡片、ViewModel／IDL 属性和三语资源，更新高级选项描述与无障碍名称。其余语言沿用现有英语资源回退。

唯一持久化意图是 `frameRefresh.vrrEnabled`，默认关闭。旧双开关的 `00／01 → 关闭，10／11 → 开启`；旧兼容字段与其损坏值均被忽略，新序列化移除该字段。损坏或缺失的 VRR 字段继续默认关闭。字段事务、重置与复制使用同一个模型，过期运行面板不能恢复旧的第二开关。调整在下次启用缩放时应用，现有不可变交换链 flags 规则保留。

### 按最终输出判定资格

Renderer 报告明确路径、倍率及前端适配器 LUID：普通 DXGI、DLSS 前端 DXGI、XeSS D3D12 代理；Composition 单独标识。前台控制器使用最终 presenter 能力和标准 VRR 合同准入，移除 FG 与 Magpie 窗口缩放模式的整体排除。

普通／DLSS 的真实帧、生成帧和同端点辅助提交仍经 `AdaptivePresenter::_PresentWithVRR`。XeSS 保持代理 `Present(0, flags)` 单次输入提交、XeLL 和 SDK 队列所有权；新增兼容上下文在整个会话内原子发布，SDK 后台线程也能读取，不要求调用落在前端线程或同步 Present 的 TLS 范围内。未改变 DLSS ring、Reflex、限帧预算或 SDK 插帧能力判断。

共享绑定读取实际 `GetDesc1()` 和 `GetHwnd()`；后者失败时用旧 `GetDesc().OutputWindow` 补取 HWND。检查 flip model 和预期输出 HWND，保存实际 flags 用于 Resize。交换链建立后按实际 Present 能力准入，避免继续沿用创建意图；Alt+Enter guard 完成后立即同步。未知或不匹配绑定撤销 VRR 资格，保留正常输出供诊断。

NVIDIA 查询替换由统一 VRR 意图派生；实际输出非 NVIDIA 时 Query 转为 Off，标准呈现继续。开发入口 `MAGPIE_GSYNC_DIAGNOSTIC=standard／trace／reference` 分别保留标准单独、查询跟踪和短时真实输出前台对照，产品只有一个开关。

### 真实输入与呈现关联

游戏继续持有真实前台并接收键鼠。目标呈现调用在有效源 capture／root 前台下返回最终交换链 HWND；业务代码继续使用原始前台入口。外部应用、主界面、源弹窗和参数宿主不伪装成源游戏。

主界面登记 HWND／PID／TID／class，并拥有独立 `MagpieMainUI` 角色。创建和销毁经 ScalingService → Runtime 的有代次保护的队列更新，覆盖托盘启动后首次打开、关闭及重建。该角色沿用既有遮挡／任务切换策略，不能获取源游戏的输入资格。

参数交接仍按现有编辑／settling 状态暂停；回到源前台后恢复。显示后的输出还需通过 live 可见性、根窗口与最小化检查，SDK 后台查询无需等待前端低频轮询即可看到隐藏或失效。隐藏启动首帧保留准入。退休继续先发布 Off，后切 owner、等待后端退出，最后禁用自身 Hook；不释放仍可能被 UI／驱动持有的 trampoline。

### 日志与后续定位

前台变化记录真实 HWND／PID、source／root／output／outputRoot／mainUI／parameterHost、角色、presenter、倍率、LUID、资格、查询计数、owner／style 与前一 Z-order 窗口。关闭开关时也记录真实前台转换，供“主界面焦点使原生驱动激活”对照。

原已命中的 NVIDIA 模块范围保持。未知来源按至多 16 个调用页、每阶段一次记录；叠加层首次命中不会遮蔽全部后续 D3D12／SDK 候选。未知来源仍返回真实前台。实际 FG 来源记录尚未采集；依据运行证据再决定是否扩展模块。
