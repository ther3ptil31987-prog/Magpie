## 布局调整

RTSS 区域的行顺序：管理范围、RTSS 状态、帧率设置、限制帧率、停止缩放后的处理。自定义与同步采用固定布局，这五行不因模式切换而增减；外层“目标窗口帧率限制”展开区保持默认展开。

- [x] **L01** 移除 `Rtss_Advanced` 内层 SettingsExpander，“停止缩放后的处理”作为外层 RTSS 展开区的直接 SettingsCard 子项，排在限制帧率之后；不再需要额外展开操作。
- [x] **L02** 停止处理行在自定义和同步模式下均可见；选择“不管理 RTSS 配置”时仍可见但禁用。把原内层展开器的 `IsRtssManaged` 启用条件直接绑定到停止处理卡片，避免移除父控件后丢失禁用规则。
- [x] **L03** 停止处理下拉框继续复用 225 DIP 的 `FrameRefreshComboBoxStyle`，由外层展开器应用同级设置行的样式；统一左侧标题缩进、右侧输入列及窄窗口换行。
- [x] **L04** 保留“保留修改 / 恢复原值”两个选项和默认“恢复原值”；已有配置选择值、会话开始时捕获停止策略及下一次开始时应用编辑的行为沿用现实现。
- [x] **L05** 清理不再使用的 RTSS 高级选项资源，更新布局、禁用状态和资源测试合同；整个“帧率与刷新”分组原有的高级选项保持原位置。
- [x] **L06** 限制帧率行始终保留：自定义模式且管理 RTSS 时可以编辑；同步模式禁用编辑，显示当前会话实际解析并取整的同步 FPS。未开始、已停止或内容跟随源而没有有效同步目标时显示“—”，不拿原手动值或读到的 RTSS 配置上限充当同步目标。
- [x] **L07** 区分手动偏好和同步显示值：同步刷新不保存到自定义值，切回自定义恢复原手动值及 15–360 的输入范围；同步值的显示不受手动范围裁剪，超过该范围时仍显示实际同步目标。显示刷新不能触发手动编辑保存或额外 RTSS 写入。

“停止缩放后的处理”在两种模式下始终位于限制帧率行下方。禁用输入框沿用同页禁用样式，不隐藏整行，不改变参数布局。

显示行为核对：当前已部署 Beta3 构建 `3c071cc6` 的生成绑定将 `ShowRtssCustomRate=false` 转换为 `Visibility::Collapsed`，应用到整张限制帧率卡片。部署 PRI 中的 ProfilePage XBF 与该编译文件逐字节一致，EXE/PRI 与构建清单哈希一致。因此“当前隐藏”已经核实，L06 是本次明确要求的布局变更。

## 控件样式 review

参照同页的内容帧率、光标刷新，以及共享 SettingsCard、SettingsExpander 和普通操作按钮。采用上方确定的行顺序，复用现有主题与尺寸资源。

| 控件或区域 | 实施前源码结论 | 复核要点 |
| --- | --- | --- |
| 三个下拉框：管理范围、帧率模式、停止策略 | 均复用 `FrameRefreshComboBoxStyle`，225 DIP、最小宽度 0、垂直居中，接入现有下拉辅助 | 核对展开后的左右对齐、短文案及中英文选项显示 |
| 整数输入与 FPS | 复用 `FrameRefreshNumberBoxStyle` 和 225 DIP 整列；整数、行内步进、FPS 间距 8 DIP，与内容帧率输入一致 | 按 L06 保持行常驻，同步时禁用编辑；核对输入高度、基线、步进按钮、焦点、占位和禁用状态，模式切换不改变整列尺寸 |
| 状态右侧工具入口与重新检测 | 两个按钮在 225 DIP Grid 中，间距 8 DIP；启动入口使用 DropDownButton，未声明与相邻输入一致的垂直对齐，也未声明局部普通按钮样式 | 重点核对高度、内边距、圆角、中性填充、边框、图标尺寸及两按钮对齐；需要修正时沿用现有普通操作按钮风格 |
| 工具弹出菜单 | 使用原生 MenuFlyout；项目页面中没有另一个 DropDownButton 作为直接参照 | 与配置列表的现有菜单对照字体、间距、明暗主题、位置和禁用反馈 |
| RTSS 主展开区与各设置行 | 使用共享 SettingsExpander/SettingsCard；设置卡片会由展开器应用子项样式 | 保留现有背景、分隔线和圆角规则，检查展开折叠后的行间距 |
| 停止缩放后的处理 | 当前仍嵌套在 RTSS 高级选项中；外层自动应用子项样式的分支仅处理 SettingsCard | 按 L01 移为直接子项，核对与帧率设置、限制帧率同级的缩进、行高、背景、分隔线、下拉列及禁用反馈 |
| 状态说明与全局范围说明 | 状态文字来自卡片 Description；全局说明采用 Caption、次级文字色和 `Margin=16,4`，与同页条件提示一致 | 精简后检查多行行高、次级文字颜色、说明缩进；去掉说明的卡片不能残留空白 |
| 窄窗口换行 | RTSS 各行启用 IsWrapEnabled，并沿用整个刷新分组统一的换行阈值 | 检查 225 DIP 输入列与按钮组合在最小窗口和高 DPI 下不挤压、不裁切 |
