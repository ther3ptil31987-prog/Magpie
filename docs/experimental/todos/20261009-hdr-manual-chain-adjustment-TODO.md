## 1 目标行为

用户在现有效果列表中自行添加、排序、编辑和移除 `HDR → SDR`、`SDR → HDR` 与 `RTX HDR`。程序检查颜色域、配对、捕获、显示器和 SDK 条件，并按用户选择的链执行；添加普通效果、拖动或修改缩放时，不替用户增删或重排转换节点。

典型组装方式：

| 意图 | 用户配置的效果顺序 |
| --- | --- |
| HDR 输入经过 SDR 效果，保留 HDR 输出 | HDR → SDR（兼容配对）→ 普通效果 → SDR → HDR（自动／恢复配对） |
| SDR 输入输出原生 HDR | 普通效果 → SDR → HDR（原生映射／无配对的自动模式） |
| SDR 输入使用 RTX HDR | 普通效果 → RTX HDR |
| HDR 输入使用 RTX 重新生成 HDR | HDR → SDR → 普通效果 → RTX HDR |
| HDR 输入输出 SDR | HDR → SDR（SDR 显示映射）→ SDR 效果 |

兼容配对存在量化和截断损失；RTX 重新生成 HDR，不等于恢复原始 HDR。无转换组件的普通旧组沿用原有 SDR 行为，不根据 Windows HDR 状态或 FP16 纹理自动启用 HDR。

## 3 保留范围

| 更新 | 调整后的要求 |
| --- | --- |
| 独立转换效果器 | 保留 HDR → SDR、SDR → HDR、RTX HDR 的独立目录条目与现有算法 |
| 手动组件模式 | 保留 HDR → SDR 的兼容配对／SDR 显示映射；保留 SDR → HDR 的自动／恢复配对／原生映射。“自动”只选择该节点的算法，不自动组装链 |
| 原生白色合并 | 保留一个有效 SDR 白色亮度，新输入 80–4000 尼特、默认 203；允许 1000／1500，不自动切 RTX、不按显示器能力强制覆盖 |
| 旧配置语义 | 保留旧 `whiteNits × exposure`、低于 80 的兼容值及原元数据语义；打开参数窗、保存其他设置不改变亮度 |
| 参数交互 | 保留精确输入、保存精度与交互步进分离、分段刻度、Shift 粗调、默认值和端点可达性，XAML 与 ImGui 使用同一合同 |
| 有效参数显示 | SDR 显示映射隐藏无效峰值；配对恢复隐藏不参与计算的独立亮度、曝光等参数，说明其上游配对来源 |
| 配对与颜色计划 | 保留手动节点的逐节点颜色域检查、配对身份及同一配对的不可变参数快照。多个独立配对保持各自参数，不跨配对联动 |
| 参数应用与会话安全 | 保留普通手动参数的即时更新／需重启规则、保存冲突与过期检查、输入释放等待、资源和历史重建；只移除组级方法切换的专用部分 |
| 图片导出 | 按实际纹理格式导出；HDR PNG 转 SDR sRGB，DDS 保留格式；导出不重复 RTX 推理 |
| RTX 生命周期 | 传播普通失败和异常，记录阶段及 SDK 状态；保留故障资源和模块，阻止不安全重初始化 |
| 启动预检 | 保留非法颜色域、缺少配对、运行库、GPU／驱动、捕获方式和显示器 HDR 条件的明确错误，不静默改变算法或配置 |

源码实现、迁移格式、回归证据和后续部署验收见[开发交接](../design/20261009-hdr-manual-chain-implementation.md)。

参数范围与步进沿用首轮合同：原生白色普通步进 5／10／50、粗调 50；HDR 参考白 5／50、峰值 10／50；曝光与肩部 0.05／0.25；RTX 峰值范围仍为 SDK 的 400–2000，普通 10／粗调 50，对比度和饱和度 5／10，中间灰 1／5。旧保存值不因这些交互刻度重新取整。

## 4 试用配置迁移

默认按“保留当前链和画面语义，展开为手动编辑”处理，不重置、删除或重新规划试用组。

- [x] 先保留可回滚的原配置，再处理组级 `hdr` 设置和 `hdrManagedRole`。对有效组直接保留已物化的效果列表及顺序，解除归属、显示全部节点，恢复手动操作权限。
- [x] 核对展开前后的捕获域、每个节点的输入／输出域、配对来源、普通效果及 FG 位置、亮度和呈现元数据，不能只比较最终像素倍率。
- [x] 特别处理“显式 HDR 输入、全程直接 HDR、没有转换节点”的试用组：单纯删除输入意图会变为 SDR 捕获。默认保留最小内部输入兼容信息，不显示新的组级入口，也不继续自动管理；不能通过插入有损转换对冒充等价迁移。
- [x] 已激活方法的值保留在对应手动节点中。未激活方法保存的偏好留在可恢复的迁移备份中，不为保存这些值额外插入转换节点；具体保存格式在实现时确定。
- [x] 损坏设置、无效节点归属或无法确认语义的配置保留原文并明确报告，不静默删节点、回退 SDR 或切换 RTX。
- [x] 迁移仅做一次，保存和重载不得重复添加节点；重复读取已迁移组保持不变。完全没有组管理字段的原手动组不做迁移。

以上兼容信息只负责已有配置的恢复和稳定执行。新配置由用户手动放置转换效果器，沿用显式组件决定捕获与输出的正常路径。
