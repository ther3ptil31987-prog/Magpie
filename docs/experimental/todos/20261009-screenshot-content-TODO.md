## 2. 用户已确定的 UI 与行为

主页 → 工具栏，在“工具栏初始状态”和“截图保存目录”之间增加一张设置卡片，标题建议 **截图内容**。使用单个三选一下拉框，选项顺序如下：

| 下拉选项 | 一次请求的文件 | 文件名示例 |
| --- | --- | --- |
| 同时截图原始输入和最终效果 | 2 张 PNG，共用一个编号 | `Magpie_001_input.png`、`Magpie_001_output.png` |
| 只截图最终效果 | 1 张 PNG | `Magpie_002.png` |
| 只截图原始输入 | 1 张 PNG | `Magpie_003.png` |

单双截图统一沿用既有目录。双截图的后缀放在扩展名之前，小写 `input`／`output`。用户明确要求的是双截图加后缀；单图方案保留原文件名，不额外改变命名规则。

该选择同时影响工具栏的普通截图按钮和对应截图快捷键。右键指定效果输出／中间通道导出维持独立功能及 PNG／DDS 规则。

## 3. 建议采用的实现约定

以下为本次方案建议，不应描述成用户额外明确指定的要求。

- **默认“只截图最终效果”**：不默认增加文件数量；旧配置缺字段、新配置和非法值均回退到此项。它与普通效果预览时的单图行为一致，但在开启“对比”时，截图会按新选择保存最终效果。
- 设置为全局值，建议存为 `overlay.screenshotContent`，枚举采用明确固定值 `InputAndOutput=0`、`OutputOnly=1`、`InputOnly=2`；缺省值为 `1`，不能依赖零初始化。
- **input**：采集区域／既有裁切后的输入画面，保持其输入分辨率，位于首个效果之前；不经过效果链、对比用的输出尺寸适配或输出颜色映射。PNG 编码需要的输入解码／颜色转换沿用正确颜色合同，因此“原始输入”指处理前的图像内容，不承诺 PNG 保存 GPU 原始字节或 HDR 原始动态范围。
- **output**：整条效果链及既有最终尺寸适配后的场景图，沿用普通截图的范围和编码路径；不叠加工具栏、参数面板、性能面板或光标。不因“对比”开关而变成 input。
- PNG 延续 Beta4 的颜色导出策略，分别使用 input 与 output 自己的格式、色域、传递函数和白点／峰值信息；不能拿 output 元数据解释 input。
- 模式在请求开始时取快照。建议主页修改后更新运行中会话的模式，仅作用于下一次请求；渲染线程读取须有明确的线程同步方式，不能直接访问主页 `AppSettings`。
- 双截图必须对应同一真实输入帧：以一次请求收集两份稳定快照，而非连续调用两个独立截图协程。输出已经是生成帧时，建议等待下一张可配对的真实处理帧；不把生成帧和邻近原始帧伪装成严格同帧。
- 输出单图优先复用最近成功呈现的最终效果快照，允许沿用既有生成帧输出；输入单图复用当前有效采集内容，按请求在首个效果前保存原尺寸快照。
- 有效静止画面也必须能够截图：不能把完成条件绑死在下一次“新内容”事件。必要时请求驱动一次真实帧处理／发布，同时保留现有去重和帧生成状态。
- 未有有效画面、窗口重建或请求等待超时时给出具体失败；禁止退回抓取桌面、使用放大对比图或混用不同会话帧。
