## 3. 统一配置与迁移规则

### 3.1 FSR3 光流

效果 ID 和参数 key 不变；保留 `1=AMDOF`、`2=NVOF`，不重新编号。删除 FSR3 marker 的 `OPTION 0 None`；method 默认 1，AMDOF quality 默认 1。

| 原配置 | 迁移/规范化结果 |
| --- | --- |
| 新建、缺省 method、重置默认 | AMDOF + 质量（1,1） |
| method=0、越界、非整数或非有限值 | AMDOF + 质量（1,1），记录原因 |
| method=1，已有合法 quality=0/1 | 保留明确选择的性能/质量；缺省或非法 quality 才使用 1 |
| method=2，已有合法 NVOF 质量 | 保留 NVOF 及质量；非法质量按既有规则规范化 |
| 其他 FG/SR 或同名参数的自定义效果 | 光流语义不改 |

缺省 method 或旧 None 按完整组合（1,1）迁移，不继承未启用时残留的 AMDOF 性能档。App 加载/导入、添加/复制、重置、运行中参数会话和直接 Core 启动必须一致。

FSR3 正常新内容的插帧要求有效外部运动。首帧/断流/reset 使用合法零纹理占位；静止场景中有效光流全零不是错误。**空闲缓存重绘不是新的插帧输入，不因缺少新运动样本而循环 reset 或报错。**

### 3.2 重复帧检测只保留通用来源

- 移除四类 FG marker、参数结构/解析与 UI 中的 `duplicateFrameFiltering`，删除 Renderer 的 FG 独立 override。
- 简单模式继续使用其既有投影（当前为 Never）；高级模式使用已有通用设置。与非 FG 共用同一策略解析，核对 3D 模式的既有规则，不再额外给 FG 一个隐藏开关。
- 当前通用值存于 AppSettings，不在本任务中改为每个配置独立存储，也不挪动现有设置布局。
- 多个旧效果组可能保存相互冲突的 0/1，不能挑其中一组覆盖通用设置。迁移通过现有备份机制保留原数据，废弃旧 FG 字段的运行作用，保持通用保存值，并记录迁移；新保存/导出不再带弃用字段。
- 旧配置/导入配置不得重新启用隐藏 override；迁移应幂等，且不改自定义效果的同名参数，不重排效果链。

两类迁移应在同一套加载/导入/运行参数规则下完成，防止只改 UI 后 Core 仍使用旧值。

## 4. 空闲重绘的运行约束

| 状态 | 行为 |
| --- | --- |
| 有新的有效内容 | 正常处理、估算运动和插帧，真实内容优先 |
| 内容/生成帧仍在排队 | 先正常消费，不让空闲旧图插队或抢占新内容期限 |
| 无新内容且空闲重绘关闭 | 保持最后有效画面，继续响应鼠标/UI、停止和新帧到达 |
| 无新内容且空闲重绘开启 | 约 500ms 无新内容后，按有效重绘率呈现稳定输出；避免将 24/30 FPS 正常间隔误判为空闲，不重新生成运动或中间帧 |
| 第一张有效输出尚未完成 | 不重绘未初始化纹理，不虚构输入 |
| 静止后恢复 | 立即让位给新内容；按 SDK 的时间/会话/资源要求恢复或必要时 reset |
| 明确捕获中断、设备错误或真实同步超时 | 沿用恢复/错误路径，不冒充正常空闲 |

- 呈现层维护空闲期限；复用已完成且生命周期有效的稳定输出，保持原有唯一内容限速职责。FG 倍率不乘到空闲重绘率上。
- DLSS/VFG 从已有稳定底图呈现扩展；FSR/XeSS 分别适配 SDK 的“不生成、只呈现”与恢复契约。需要切换生成状态时在空闲状态转换处进行，避免每次重绘排空 SDK。
- 捕获 ID、时间戳、光流帧对不因重绘变化；SDK 若要求额外呈现序号，单独维护，不能伪造成新捕获。Stop/Resize/新内容均可打断等待，避免忙等。
- 仅重绘透明 overlay 不等于重绘内容。实现过程中暂未适配的 provider 应明确标示限制，但**不能据此将四类 FG 的最终目标标为完成**。
- 静态缓存重绘不无条件重跑所有前置效果；依赖时间的动态效果有独立语义，须明确处理边界，不能错误冻结已有动态输出或把它伪装成新捕获。
- 不引入新的近似去重算法、视频帧率猜测或按应用名识别策略。AABB 等重复序列保留真实时序含义，不能去重后伪造间隔。
