RTSS 状态信息按内容类型分段，优先同行显示，空间不足时整段换行。状态右侧按“初始化 Magpie → 启动工具 → 重新检测”排列，统一普通操作按钮样式。初始化为 Magpie 建立独立不限帧配置，已有配置仅清除限帧，其他设置保留。喜鹊启动时默认请求管理员权限，供 RTSS 配置写入使用。

## 已确认需求

| 项目 | 行为 |
| --- | --- |
| 状态顺序 | 配置对象、RTSS 版本、操作结果、当前 FPS、具体错误、事实提示；有信息的项才显示 |
| 状态换行 | 优先同行排列；当前行容不下下一段时，将该段整体移至下一行；单段超过整行宽度时才在段内换行，不截断、不省略 |
| 操作按钮 | 新初始化按钮位于启动工具左边；与启动工具、重新检测共同采用已有普通按钮的中性填充、零边框和状态反馈 |
| 缺失 Magpie 配置 | 创建 RTSS 的 Magpie 独立配置，将 FPS 与帧时间限制归零 |
| 已有 Magpie 配置 | 只将限帧归零，保留其他设置；已经不限帧时不重复写入 |
| 初始化生命周期 | 点击执行并持久保留，不随停止缩放撤销，不受当前游戏配置的停止策略影响 |
| 启动权限 | Magpie 主程序启动时默认请求管理员权限；已具备管理员权限时直接继续启动 |

初始化按钮短名称使用“初始化 Magpie”，工具提示说明为 RTSS 建立 Magpie 不限帧配置。同一行示例：`Global - RTSS 7.3.5.28314 - 已恢复原帧率设置`。
