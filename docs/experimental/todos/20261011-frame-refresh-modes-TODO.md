- 高级 RTSS 的作用范围、独立帧率及停止策略，以及处理节奏、光标、重复帧检测偏好继续独立保存。简单模式接管运行行为，不能把其投影值写回覆盖高级偏好。
- **高级模式的重复帧检测默认关闭。** 新设置、字段缺省和恢复默认使用 Never；保留已有明确保存的动态 / 总是检测选择，不在打开页面、重启应用或切换模式时反复重置。简单模式继续关闭本组重复帧检测。补帧效果自身独立的 `duplicateFrameFiltering` 不属于本次默认值调整。
- 保留模式及参数在下次缩放 / 保存并重启时生效的规则。工具栏实时参数面板不增加模式切换，并需核对新的共享字段和运行策略，避免回写第一阶段“简单模式强制关闭 VRR / RTSS”的旧投影。

### RTSS 自动准备与状态

- 用户启用目标程序限帧后，在开始缩放时自动检查 RTSS；已安装但未运行则自动启动，按需将 Magpie 自身 RTSS 配置初始化为不限帧，再加载并应用目标限帧配置。已运行、已初始化时复用现状。
- “初始化 Magpie”指处理 Magpie 自身的 RTSS 限帧配置，不是安装 RTSS，也不是重置目标程序或 Global。MSI Afterburner 保持可选工具，不作为 RTSS 联动的启动依赖。
- 未安装时显示“未安装 RTSS”和获取入口；不能仅凭安装检测就写成“未下载”，也不自动下载或安装。安装后提供重新检测入口。
- RTSS 状态行放在帧率控制内的目标程序限帧下方，简单 / 高级共用，不另增顶层设置组。至少区分：未安装、等待开始缩放、正在检测、正在启动、正在初始化 Magpie、正在加载限帧配置、已就绪、联动未完成。另覆盖未启用和跟随源时等待固定目标的状态。
- 就绪状态使用“配置限帧：N FPS”等准确结果，不把配置读回或重载请求等同于实测目标帧率。已保存但重载失败等部分完成结果应保留真实状态。
- **准备或联动失败时继续缩放。** 状态行显示“RTSS 联动未完成”、简短失败原因及“缩放继续运行”，提供重试。重试作用于当前有效会话和目标，不重启或中断缩放。
- 正常状态保持简洁，状态对应的必要操作就近展示；重新检测、重新初始化及已有工具入口归入管理区域，避免始终平铺多个按钮。原有手动恢复入口保留。
- 自动准备沿用串行 worker、能力检查、文件事务及会话身份；不在 UI / 渲染线程阻塞，不逐帧启动、初始化或重复写配置。失败不无限自动重试；停止、取消或切换会话后，旧任务不能继续应用或发布到新会话。
- 停止缩放按本次有效 RTSS 退出策略处理配置；不因状态 UI 重构而清空外部已有设置或退出用户的 RTSS / Afterburner 进程。
