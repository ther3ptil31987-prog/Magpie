# v0.6.10 Beta6

基于 Beta5 修复 VFX 与 RTSS review 中确认的问题，保留现有配置兼容、UWP、VRR、截图与其它功能。

- 修复共用参数分组字符串生命周期错误，避免长中文分组标题重复和布局抖动。
- TrueHDR 依赖预检匹配实际构建后端，并记录缺失组件；Upscale/TrueHDR 遵守模型 RGBA 输入合同，Upscale 使用独立 RGBA HDR 边界，校验私有尺寸适配的输出纹理。
- HDR10/scRGB 转换保留合法负通道；统一繁体 TrueHDR 故障提示。
- VFG 关闭帧同步时仍创建消费事件，处理等待失败；独立统计窗口避免等待计数下溢。
- VSR 参数/尺寸按完整事务保存，恢复启动值包含原尺寸；动态缩放菜单同步分类，相同档位列表不再重复 Reset。
- 旧 Denoise 由旧身份决定降噪语义；合法 HDR 恢复链执行精确 RTX 兼容迁移，保留原始备份和顺序。旧后端回退正确映射 Standard/Denoise，明确拒绝不支持的其它分类。
- 删除参数页常驻 VFG/Upscale 内部流程说明；补齐箭头字形并升级字体缓存。
- RTSS 操作区对齐统一控件列，初始化后隐藏按钮并扩展工具按钮；未知/读取失败与明确未初始化分开判断。
- TrueHDR 实时参数在原模型上批量更新，重复值跳过 SDK；设置失败恢复完整旧参数，回滚失败停止继续渲染。
- 停止会话后拒绝旧参数请求，原后端线程排空并释放原生效果；记录 SDK、互操作、释放和等待线程的阶段与耗时，便于定位再次启动故障。
- DLSS FG、XeSS FG、VFG 的新建及缺省重复帧过滤默认关闭，保留已有显式设置。
- RTSS 启动工具的文字、箭头、内容间距及交互状态采用同页下拉框资源，刷新图标按钮保持原尺寸。

本地发布，未推送远端。包内 build-manifest.json 记录实际提交、构建选项和文件哈希；本轮验证范围和实际游戏/显示器验收状态见工作区 reports/0610-beta6-hdr-live-fixes-20261010，前一轮 VFX review 修复见 reports/0610-beta6-vfx-rtss-fixes-20261010。
